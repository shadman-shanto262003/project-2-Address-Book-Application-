📒 Address Book Application (Java)<br>
📌 Overview
<br>
This is a simple Address Book Application built using Java.<br>
It allows users to manage contacts efficiently by performing basic operations like adding, deleting, searching, and displaying contacts.<br>
<br>
🚀 Features<br>
➕ Add new contact<br>
❌ Delete existing contact<br>
🔍 Search contact<br>
📋 Display all contacts<br>
🧭 User-friendly menu system<br>
🛠️ Technologies Used<br>
Java (Core Java)<br>
Swing / AWT (GUI Forms)<br>
File Handling (.txt file for storing data)
