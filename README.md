📒 Address Book Application (Java)
📌 Overview

This is a simple Address Book Application built using Java.
It allows users to manage contacts efficiently by performing basic operations like adding, deleting, searching, and displaying contacts.

🚀 Features
➕ Add new contact
❌ Delete existing contact
🔍 Search contact
📋 Display all contacts
🧭 User-friendly menu system
🛠️ Technologies Used
Java (Core Java)
Swing / AWT (GUI Forms)
File Handling (.txt file for storing data)
